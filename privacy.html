Privacy Policy / 개인정보처리방침

chat-shorts-uploader is a personal tool used only by its developer to upload videos to the developer's own YouTube channels.

What the app accesses

  • The app asks for permission to upload videos and manage the YouTube account (YouTube Data API v3 scopes youtube.upload and youtube.force-ssl) for the Google account that the developer signs in with.
  • It uses that permission only to upload videos the developer made and to set their title, description and publish time.

What is stored

  • The OAuth token is stored as a local file on the developer's own computer. It is not sent to any server other than Google's.
  • The app does not collect, sell, share or transfer any user data to third parties. There is no analytics and no advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services and is subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
